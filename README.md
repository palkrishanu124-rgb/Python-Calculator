# Python Calculator

A command-line calculator application built in Python. It includes multiple categories of mathematical functions and is designed as an interactive menu-driven program.

## Features

- Arithmetic operations
  - Addition
  - Subtraction
  - Multiplication
  - Division
  - Modulus
  - Exponentiation
- Algebraic functions
  - Linear equations
  - Quadratic equations
  - Quadratic expression evaluation
- Trigonometric functions
  - Sine, cosine, tangent, and reciprocals
  - Inverse trigonometric functions
  - Hyperbolic and inverse hyperbolic functions
  - Degree/radian conversion
- Geometric calculations
  - Circle
  - Rectangle
  - Triangle
  - Square
  - Cuboid
  - Sphere
  - Cylinder

## Project Structure

- `PythonApplication3/PythonApplication3.py` - Main calculator program
- `PythonApplication3/PythonApplication3.pyproj` - Python project configuration
- `PythonApplication3.slnx` - Solution file

## Run the Project

From the repository root, run:

```bash
python "PythonApplication3/PythonApplication3.py"
```

Or open the project in Visual Studio/Python tools and run the startup file.

## How it Works

The program displays a main menu with several categories:

1. Arithmetic
2. Algebraic
3. Trigonometric
4. Geometric
0. Exit

After selecting a category, the user is guided through prompts to enter numeric values and choose options for the corresponding calculations.
